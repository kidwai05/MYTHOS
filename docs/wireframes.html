Mythos wireframes (Phase 1)

Low-fidelity layouts for the three core screens. Numbered circles match the notes under each screen. Content shown is placeholder.

1. Character profile

  1. Image with credit and licence (NFR-11, FR-3). Name, aliases, role and domain chips.
  2. Sources panel lists every link with its locator and a verified or unverified badge. This is the project's differentiator.
  3. Equivalents panel (FR-5). Empty until Phase 5.
  4. Relationships grouped by type (FR-4) with a button into the graph (FR-12).

2. Search and filters

  1. Free-text search with autocomplete (FR-7, FR-10).
  2. Combinable filters: mythology, role, domain, gender (FR-8). State is kept in the URL (FR-11).
  3. Sort and pagination (FR-9).
  4. Card with a quick bookmark button (FR-23).

3. Graph explorer

  1. Controls: centre character, depth 1 to 3, edge-type filters, switch to family tree (FR-12, FR-13, FR-15).
  2. Legend: colour and dash style encode relationship category (FR-14).
  3. Preview card with the source for the clicked edge, and a link to the profile (FR-16).
  4. Shortest-path finder (FR-18, stretch goal).
